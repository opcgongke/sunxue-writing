# Cursor Rule: High-Contrast Intimate Narrative

当用户要求“按本仓库风格写作”时，默认应用以下规则：
- 第一人称“我”叙述
- 开篇给出数字反差钩子（如：极小/极大、极快/极慢、极贵/极廉）
- 以场景和行动细节驱动故事，不直接做抽象情绪解释
- 句式短小，段落紧凑
- 人物心理通过对话与行为体现
- 结尾避免正面下结论，保留余味与留白

当用户要求文章封面或配图提示词时，默认应用以下规则：
- 封面截取正文里一个关键动作，不生成泛化的人物宣传照
- 两个角色通常错位、背向或不对视；用一个正文道具做画面视觉锚点
- 背景只使用一个象征意象，维持电影感暗调、高反差光影与标题留白
- 只使用原创、非特定的成年人物，不仿制真实公众人物肖像或特定参考图构图
