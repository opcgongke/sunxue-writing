# 孙学写作叙事

孙学、孙宇晨写作叙事风格，来自《我的女友景甜》蒸馏而成。

## 简介

核心能力：

- **风格化改写**：将已有文本重写为“孙学写作叙事”风格。
- **风格化生成**：按给定题材、人物和关键元素直接生成同风格文章。
- **情节型封面**：把正文里最有事的一秒拎出来，生成一张“还没点开就知道这瓜不简单”的原创电影感封面提示词。

风格特征（适合“看完就想发条评论又怕卷进去”的人）：
- 第一人称叙事，像在讲真事一样像在控场。
- 短句、快切镜头、场景密度高（酒店、航班、打款、对话、停顿都要上）。
- 开头数字反差钩子，先让读者“这也能写成故事？”；
- 情绪不喊口号，用动作和环境替你“替他解气”；
- 前后呼应收束，最后把钩子收回去，不给用户一个完整答案（更容易回味、更容易传播）。
- 配图不当人物宣传照：两人错位、不对视，一个关键道具站到画面中央，背景只留一个象征意象。图先把悬念递过来，正文再慢慢下刀。

## 安装方式（通用）

1. 将仓库作为 Skill 加载到目标 Agent。
2. 主入口使用 `SKILL.md` 作为规则。
3. Cursor 用户可额外读取 `.cursor/rules/writing-style.md` 以启用本地规则增强。
4. 如果你是“直接复制就想发朋友圈/公众号”的用户：先用 Rewrite 先试一段，顺手再切 Generate；需要配图时用 Cover Image Prompt，让封面先把围观群众叫进来，正文负责让他们别走。

## 文件说明

- `SKILL.md`：主规则文档（风格、结构、改写/生成模式、示例）。
- `manifest.json`：标准化元数据（版本、能力、说明字段）。
- `skillhub.json`：面向 SkillHub/聚合市场的兼容清单（本次新增）。
- `CHANGELOG.md`：版本更新历史。
- `.cursor/rules/writing-style.md`：Cursor 编辑器规则入口。
- `LICENSE`：许可证说明。
- `examples/rewrite_prompt.md`：改写模式示例。
- `examples/generate_prompt.md`：生成模式示例。
- `SKILL.md` 的“封面叙事”章节：封面构图规则、图文一致性检查和图像提示词模板。
- `CONTRIBUTING.md`：贡献说明（可选）。

## 使用模式

- **Rewrite（改写）**：输入一篇现有文章，保留核心事实与逻辑，改写为本 Skill 风格。
- **Generate（生成）**：输入主题/背景/关键元素，直接按风格生成新文本。
- **Cover Image Prompt（封面）**：输入文章，得到一条表现关键情节而非泛氛围的原创配图提示词。
